How this is measured

One fresh headless Chromium chromium 151.0.7922.34 profile per site, no stored cookies, one page load, a 3s pause between sites. Buttons are found and classified by fixed text rules. When the rules find no accept or reject button, a local LLM (gemma-4-12b) is asked only which button is which; it never decides a score. It was consulted on 10 sites (12 calls) and its answer decided a button on 4; rows say so, and every call is logged in that site's evidence.json. Bot walls and CAPTCHAs are never solved or bypassed: those sites are listed as unmeasurable. Trackers are third-party requests (by registrable domain and Disconnect entity) to domains in the Disconnect tracking-protection list (Advertising, Analytics, Social, Fingerprinting, Cryptomining) seen before the first click.

Score v1 starts at 100: −15 per extra click reject needs over accept (max −45), −40 if no reject path is found within two layers, −30 for a pay-or-ok wall, −5 per pre-ticked toggle (max −20), −3 per tracker domain fired before consent (max −40). Grades: A ≥ 90, B ≥ 75, C ≥ 60, D ≥ 40, F below. "Verified" means the banner was gone after the reject path and no consent buttons remained.

Limitations: only the largest banner is measured; settings are followed two layers deep; pre-ticked legitimate-interest toggles on tabs that were never opened are not counted; a single run from a single connection.
